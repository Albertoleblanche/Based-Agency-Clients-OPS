# Deploying the Client Update Workflow outside Claude Everything code-related is done. Three things need a human to click through them — here's exactly what to do, in order. ## 1. Create the database (Supabase) 1. Go to https://supabase.com → sign up (free) → **New project**. 2. Once it's created, go to **SQL Editor** → **New query**. 3. Paste in the entire contents of `schema.sql` (in this folder) and click **Run**. As features got added over time, several more `schema-*.sql` files were created (`schema-auth.sql`, `schema-notes.sql`, `schema-time.sql`, etc., including the newest, `schema-payroll.sql`) — run each of those the same way, in your SQL Editor, after the base `schema.sql`. 4. Go to **Settings → Data API** (Supabase split this out from the old single "API" page). The **Project URL** is at the top there. For the key, either: - Click the **Connect** button near the top of the project dashboard — it shows both values pre-filled, ready to copy, or - Go to **Settings → API Keys**. Use the **Legacy API Keys** tab and copy the `anon` `public` key, OR use the newer **Publishable key** (`sb_publishable_...`) — both work identically for this purpose.
