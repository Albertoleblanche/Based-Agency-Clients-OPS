Your Name

Set once per person — auto-fills whenever you log an improvement, so you don't type it every time.

Client Field Options

Add or remove the choices available in the Service and Status dropdowns when adding/editing clients. Importance (1–10) and Danger (1–5) are fixed numeric scales.

Custom Fields

Add your own fields to the client form — Website, Phone Number, anything you need. They'll show up when adding or editing a client, and on each client's detail page. Reorder with the arrows; deleting a field hides it going forward but keeps existing values.

Danger Score Suggestion

The danger score itself always stays a human call — whoever's editing a client picks the number. What these control is the nudge shown alongside it: how much weight each signal gets when suggesting a score is worth reconsidering. Set anything to 0 to ignore it entirely.

Assistant AI Provider

Which AI actually powers the Assistant tab and floating button — this only affects the Assistant, not the email draft generation on each client. Whichever you pick needs its own API key already set up on the server; picking one without its key configured will show an error, not silently fall back to the other.

Exact model string sent to each provider — the Assistant's weekly proactive-insights check (and, for OpenAI, per-client draft generation too) uses whichever is set here. Update this instead of redeploying code when a provider deprecates or renames a model.

Your Email Structure & Instructions

Tell the AI exactly how you want your own client emails structured — greeting style, paragraph order, sign-off, tone, length, anything. This is personal to you — it only applies to drafts you generate, and nobody else's drafts are affected by it, the same way nobody else's changes here affect yours. A few rules always apply no matter what you write here: every improvement must be described as a specific, measurable deliverable (never vague claims), and nothing that could make the agency look bad.

Google Sheet Sync

Live pull (Sheet → App): In your Google Sheet, go to File → Share → Publish to web, choose the specific tab, select CSV, and publish. Paste that link below. This reads the sheet — it can't write back to it.

Columns recognized (any order, case-insensitive): Name, Email, Service, Status, Importance, Danger, SOW.

If publishing to web isn't an option, paste the sheet's cells directly (select all in Sheets, copy, paste here):
